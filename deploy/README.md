# Gatz. Hub Reservation — مجلد النشر (Netlify)

## الخطوات (دقيقتان)

1. افتح 👉 **https://app.netlify.com/drop** في متصفحك.
2. اسحب مجلد `deploy` كاملاً وأفلتـه في المنطقة اللي تظهر.
   - أو اضغط **"Browse files"** واختر كل الملفات جوه المجلد.
3. Netlify هيجهّز الموقع ويعطيك رابط جاهز زي:
   ```
   https://xxxxx.netlify.app
   ```
4. افتح الرابط → هتلاقي التطبيق شغال فوراً ✅

## ملاحظات مهمة

- الرابط **دائم ومجاني** — ما بيوقفش زي أنفاق Cloudflare/Serveo.
- كل الملفات هنا نسخة من التطبيق الحالي (نفس التصميم + Supabase + الشعارات).
- `index.html` هي الصفحة الرئيسية → الكمبيوتر والموبايل يفتحوا نفس التطبيق.
- **ما تحتاجش تضبط «رابط التطبيق العام»** في الإعدادات — الرابط هيُستخدم تلقائياً في دعوات واتساب لأنه الرابط الحالي.
- لو حابب تربط دومين خاص بك لاحقاً: Netlify → Domain settings → Add custom domain.
